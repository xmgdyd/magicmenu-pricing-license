## 功能不少，但这几个限制要先知道

官方列出的功能覆盖面确实广。新建文件支持 TXT、Markdown、Word、Excel、PPT、Keynote、Pages 这些常见格式，还有复制或移动到指定文件夹、常用文件和网站快速访问、连残留一起删干净的卸载、重复文件与相似照片清理、图片转 PNG/JPG/WEBP、压缩、截图录屏、复制文件路径、隔空投送、隐藏私密文件，以及用 VSCode、Terminal、iTerm2 这类工具直接打开文件。全部挂在系统右键菜单里，不需要额外开窗口。

限制也比较实在，先说最要紧的一条。

**授权绑定到机器的序列号上。** 官方 FAQ 明确只承诺“同一台 Mac 重装系统不限次数激活”，换一台新电脑算不算、要不要重新买，页面上没有给出承诺。你如果是那种两三年换一次 Mac 的人，这一点比价格更值得先想清楚。

**自动续费默认开启。** 年付买完不是到期提醒你，而是直接扣。想停的话，记得在账户里取消。

**标价不含税。** US$19.95 和 US$59.95 后面都标着 excl. VAT，部分地区的结算页会加上当地增值税，最终金额会比标价高一些。

**独立测评很少。** 我能找到的多是软件目录站的收录条目，功能描述抄的是官方文案，缺少长期使用报告。这类深度集成到系统右键菜单的工具，出问题通常集中在 macOS 大版本更新之后。买之前心里有个数，别指望买完就一劳永逸。
